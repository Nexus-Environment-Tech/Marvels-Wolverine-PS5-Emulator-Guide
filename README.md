## 💎 Graphics & Technology

Marvel's Wolverine is one of the most technically advanced PS5 exclusives:

### Real Geometry Damage
Logan's wounds, cuts, and bruises are **actual geometry changes** on the character model — not textures or decals.

### Blood Particle System
VFX artists simulate blood flow in **Houdini**, then the game plays it back in real time. Particles react to wind, surfaces, and water.

### Destructibility
A huge number of environment objects are **pre-fractured** and react to hits. Each object inherits the speed and direction of the attack.

### PS5 Pro & PSSR
On PS5 Pro, the game runs in **Performance Pro** mode with upscaling to 4K at 60 FPS thanks to PSSR.
